# ProblemRadar

MVP UI for ProblemRadar — a research product for discovering real,
evidence-backed problems worth solving. Built with Next.js, TypeScript,
Tailwind CSS, and shadcn/ui.

Full documentation lives in [`docs/`](./docs/README.md):

- [`docs/README.md`](./docs/README.md) — project purpose, scope, stack, folder structure
- [`docs/UI-ARCHITECTURE.md`](./docs/UI-ARCHITECTURE.md) — page flow and component responsibilities
- [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md) — running the project and contribution rules

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
